# sjb-stack

A collection of my favorite AI skills, automations, tools, APIs, workflows

## Favorite skills from others

- [Impeccable](https://github.com/pbakaus/impeccable): design language that makes AI coding agents better at frontend design
- [Motion AI Kit](https://motion.dev/docs/ai-kit): the official Motion skill and MCP for motion animations ([source](https://github.com/motiondivision/ai-kit))
- [React Best Practices by Vercel](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices): React and Next.js performance guidelines for agents
- [Emil Kowalski's skills](https://github.com/emilkowalski/skill): UI polish and animation taste
- [Frontend Design by Anthropic](https://github.com/anthropics/skills/tree/main/skills/frontend-design): avoids the generic AI look
- [shadcn/ui](https://ui.shadcn.com/docs/skills): shadcn components done right
- [Supabase](https://github.com/supabase/agent-skills): Supabase and Postgres best practices
- [Remotion](https://www.remotion.dev/docs/ai/skills): make videos in React

## Tools I use

- [Aside](https://aside.com): AI browser that does the work for me, like job applications, outreach emails, event RSVPs, and research. Feels like the missing step to what AI can actually do for you ($0 with an existing AI subscription)
- [Gamma](https://gamma.app): AI presentation builder, my last semester of university depended on it
- [Reve](https://app.reve.com): images and graphics that don't look like AI slop
- [Motion.so](https://motion.so): AI for motion graphics, better than Hyperframes or Remotion (a bit pricey)
- [Monid](https://monid.ai): one API key for everything you'd want an agent to do
- [Google AI Studio](https://aistudio.google.com): a bit janky, but tons of control over image and video generation

## Free open-source alternatives

[Mann Bellani](https://github.com/Blueturboguy07) clones paid apps and open-sources them for free. Some of his:

- [cue](https://github.com/Blueturboguy07/cue): free Cluely, an AI copilot that sees and hears your meetings and stays hidden from screen shares
- [WhimprFlow](https://github.com/Blueturboguy07/WhimprFlow): free Wispr Flow, local voice dictation
- [lunara](https://github.com/Blueturboguy07/lunara): free Flo, a private cycle and fertility tracker
- [publikclip](https://github.com/Blueturboguy07/publikclip): free OpusClip, turns long videos into short vertical clips
- [NitroAI](https://github.com/Blueturboguy07/NitroAI): turns lectures, PDFs, and videos into notes, flashcards, and quizzes

His startup [Publik](https://publikhq.com) puts all of these free alternatives in one place so anyone can find and install them. The apps are free to install. You only pay for the resources you use inside them, not the software.
